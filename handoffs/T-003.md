# T-003: 修复打包漏项并交付双安装方案

## Goal

发布可放心宣发的 `v0.4.1`：Windows/macOS 成品包含 Grok/Qoder 共享恢复层，并同时提供 Agent 一句话安装与 GitHub Release 下载安装，两条路径都会自动发现本机数据源并向用户的 Agent 写明安装路径和使用方法。

## Scope

- 修复 PyInstaller 对 `agent_recovery` 动态模块的漏包，并移除尚未接入插件的误导性宣传。
- 为 Windows/macOS 构建后成品增加启动、健康、数据源与 Grok/Qoder 模块冒烟测试。
- 扩展 Agent 安装器：自动发现路径、安装两个 Skill、安全登记 Codex/Grok MCP、生成本机 `AGENT_USAGE.md`。
- 增加一份可通过 URL 交给 Agent 执行的一句话安装协议，兼容有/无 Git 的 Windows/macOS 环境。
- 让 Release 下载版首次启动也自动写入数据源配置和 Agent 使用说明，并在压缩包中附带接入脚本/说明。
- 修正文档中的版本、适配器数量、插件状态和双安装入口。
- 验证、提交、创建 PR、通过三平台 CI、合并 `main` 并发布 `v0.4.1`。

## Do not touch

- 不写入、移动或迁移任何厂商会话数据库；只探测并保存路径。
- 不覆盖用户已有 Skill 以外的文件，不删除 Agent 配置，不写入凭据。
- MCP 配置只能幂等更新 `conversation-hub` 自己的区块；不能破坏其它 MCP。
- 不启用未接入的腾讯记忆插件，不对外开放 localhost 服务。
- 不 force-push，不改写 `v0.4.0`，不发布 `v0.4.1` 以外的版本。
